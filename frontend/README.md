# 📱 EMSI RAG Frontend — Application Flutter

Ce dossier contient le frontend mobile développé en Flutter pour l'application **EMSI RAG & Supabase Auth**.

## 🚀 Fonctionnalités
- Authentification avec Supabase (Connexion, Inscription, Déconnexion, Gestion de session).
- Interface de chat conversationnel RAG avec streaming des réponses en temps réel (SSE via FastAPI).
- Visualiseur webview intégré pour inspecter la base vectorielle ChromaDB.

Pour les instructions complètes d'installation et de configuration, consultez le [README principal à la racine du projet](../README.md).
